# 基于简历的全栈面试考试系统 PRD

## 目标

为候选人准备目标公司全栈工程师岗位的技术面试。系统把个人简历、岗位 JD 与项目材料转换为可考试、可评分、可追踪的本地学习闭环：先进行一轮 50 道客观选择题的笔试并即出分，再进入由 LLM 驱动的模拟面试，即时评分并输出逐题报告。

## 已确认范围

- 单用户，无登录。
- Vue 3 + TypeScript + Element Plus + Pinia + ECharts + CodeMirror 6。
- FastAPI + SQLAlchemy 2 + Alembic + SQLite。
- 只使用 uv，兼容 Windows 与 Ubuntu；Windows 为主要验收环境，不提供 Docker。
- `python install.py` 安装依赖并构建前端；`uv run python start.py` 迁移数据库、启动服务并打开浏览器。
- Vue 构建产物由 FastAPI 提供，日常使用只有一个端口（默认 `127.0.0.1:8000`）。

## 初始化流程（简历 + JD）

- 简历（PDF）与岗位 JD 均为必填；无简历或未解析时进入引导上传，未配置模型时引导去设置页配置。
- 调研 Agent 使用模型原生 `web_search` 结合简历与 JD 检索真实面试题，产出 50 题规划表（领域 ≥ 3、难度重平衡），规划表需用户确认后才开始生成。
- 确认后一次性生成 50 道客观选择题（全部为选择题，无主观题），分块生成、单块失败可重试，最终仍缺失的题标记为"待补"。

## 笔试

- 50 道客观选择题、60 分钟、无检查点、交卷即出分；满分 100。
- 成绩按领域统计能力分，联动"优先补强"弱项清单；弱项用于驱动模拟面试提问。

## 评分

- 客观选择题自动评分，无主观题评分。
- 主观表达评估统一进入模拟面试环节，由面试官逐轮即时评分。

## 模拟面试

- 面试蓝图 6-8 问：开场 1 + 项目深挖 2-3 + 技术 2 + 行为 1-2 + 收尾 1，由生成 Agent 基于简历/JD/笔试弱项生成并经校验（自动补开场/收尾、过滤未知题型）。
- 面试官主导对话流：一轮一问，可查询题库辅助（`query_bank` 工具）、追问 ≤ 2 层、可提前结束；即出分并记录到对应蓝图题。
- 行为题内置模板（宝洁八大问）+ 简历定制，不联网搜索。
- 报告：面试结束（自然结束或提前结束）后生成，含总体评分、逐题评分、改进建议、参考答案要点与考察原则。
- 可重复进行，历史会话与报告永久回看。

## 大模型

- OpenAI-compatible 接口；`.env` 三变量（`LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`）作默认，设置页「模型提供方」可动态配置自定义提供方（显示名 / BaseURL / API Key / 模型），配置存库即时生效。
- 全硬依赖：出题、调研、面试、报告均需模型；未配置时界面引导配置，不静默降级。
- 推理模型工具往返需回传 `reasoning_content`；搜索使用 Anthropic 兼容端点的原生 `web_search_20250305` 工具，`ddgs` 仅作兜底。

## 数据边界

- 调用模型时只发送当前题目、评分要点、用户答案与必要的脱敏项目摘要；不得发送完整简历原文、源代码、手机号、邮箱或本地路径。
- 面试长对话采用滑动窗口 + 自动摘要，保留上下文的同时控制 token 成本。
- SQLite 启动时按日期备份，保留最近 10 份；数据仅存本地。

## 验收接缝

- 公共接口级验收：FastAPI HTTP API（初始化/组卷/交卷/评分/面试会话 SSE）、前端浏览器流程（初始化 → 笔试 → 模拟面试 → 报告回看）、命令入口（`install.py` / `start.py`）。
